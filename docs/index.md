# Firefox MCP Connect

Firefox MCP Connect (the Claude plugin) and Claude MCP Connect (the Firefox add-on) let Claude use your own Firefox through a local, code-protected connection. It's an independent community project, not affiliated with Anthropic or Mozilla.
